# TypeScript DSA Journey

## About This Repository

This repository documents my journey of revisiting and strengthening my programming fundamentals, Data Structures, and Algorithms (DSA) using TypeScript.

After building backend projects and production-style systems, I am going back to the fundamentals to improve my problem-solving skills, algorithmic thinking, and prepare for technical interviews.

This repository covers:

- Programming fundamentals from the ground up
- Variables, data types, operators, conditions, and loops
- Functions and problem-solving basics
- Arrays, strings, objects, Maps, and Sets
- Algorithm fundamentals and complexity analysis
- Core data structures and their implementations
- Problem-solving patterns and approaches
- Practice exercises before LeetCode/NeetCode
- LeetCode and NeetCode problems with explanations
- Notes, solutions, and implementations from scratch

The goal of this repository is not only to collect solutions but to understand the reasoning behind each algorithm, data structure, and the situations where they should be applied.

Each folder represents a step in my learning process, creating a complete record from fundamental concepts to advanced DSA.
